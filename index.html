Помощь

Всё хранится на этом устройстве. Если приложение удалить или очистить его данные, вопросы и прогресс могут исчезнуть. Регулярно сохраняй копию.

«Добавить вопросы» принимает один JSON, несколько JSON одновременно либо ZIP с JSON-файлами. ZIP распаковывается на устройстве, без отправки файлов на сервер. При совпадениях ID приложение предложит применить исправления.

«Обновить раздел» полностью заменяет выбранный раздел. Старые вопросы, отсутствующие в новом файле, исчезнут из этого раздела; остальные разделы останутся.

Импорт работает локально. Не публикуй служебные руководства и закрытые материалы в GitHub без разрешения.
